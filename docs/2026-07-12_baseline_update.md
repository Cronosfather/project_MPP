# 2차원 정상해석 업데이트 — 2026-07-12

## 형상 정의 수정

초기 형상은 입구와 디퓨저 출구 높이를 절대 좌표로 고정해 큰 지상고에서 목 곡선이 상부 형상과 교차했다. 동일한 언더플로어를 수직 이동한다는 조건을 만족하도록 입구와 출구를 각각 `h + 0.06L`, `h + 0.10L`로 수정했다. `h/L=0.10` 형상은 수정 전후가 동일하다.

## h/L=0.30 결과

- medium 격자 생성 성공
- 1차 안정화: 326회에서 `rms[P] < 1e-8`
- 1차 수렴해 기반 2차 continuation: 3,000회 실행
- 마지막 `rms[P] = -6.731`
- 마지막 200회 평균: `CL=-0.8219`, `CD=0.06061`
- 상대 범위: CL 2.25%, CD 1.21%
- 판정: `provisional`

높은 지상고에서도 2차 정확도 힘이 느리게 표류하므로 현재 병목은 저지상고 박리보다 정상해 수치 수렴 설정일 가능성이 크다. 다음 시험은 저장된 `h/L=0.30` 해에 `MGLEVEL=3`을 적용하는 것이다. 이 시험은 실행 사용량 한도로 시작되지 않았으며 결과가 아니다.

## Multigrid continuation 결과

`MGLEVEL=3`으로 세 번의 2,000회 continuation을 수행했다. 최종 마지막 200회에서 `CL=-0.67718`(평균), `CD=0.057750`이며 상대 범위는 각각 0.134%, 0.692%였다. 마지막 `rms[P]`는 -7.368이다. 엄격 기준(`rms[P] <= -8`, 힘 상대 범위 0.5%)은 통과하지 못했지만 선별 기준(`rms[P] <= -7`, 힘 상대 범위 1%)은 통과했다.

결론적으로 이 결과는 정상 다운포스 곡선의 최종 검증값이 아니라 다음 지상고 조건을 선별하기 위한 `screening` 결과로만 사용한다. 엄격 검증은 격자 독립성 및 필요 시 URANS 시간평균과 함께 다시 수행한다.
