# 실행 기록

## 2026-07-12 — 최초 2차원 정상 RANS 기준해석

- 도구: Gmsh 4.15.2, SU2 8.5.0 Windows OpenMP
- 조건: `steady2d_h_0p1_medium`, `U=40 m/s`, SST-2003m, moving ground 40 m/s
- 격자: 82,369 nodes, 152,649 elements
- SU2 8.5 문법에 맞춰 `SURFACE_MOVEMENT=MOVING_WALL`, `MARKER_MOVING=(ground)`, `SURFACE_TRANSLATION_RATE=40 0 0`을 적용했다.
- 2차 정확도 직접 시작은 잔차와 힘이 장기간 표류했다. 1차 정확도 continuation은 270회에 `rms[P] < 1e-8`을 만족했으나 수치확산이 커 최종값으로 사용하지 않는다.
- 1차 수렴해에서 재시작한 2차 정확도 계산도 3,000회 후 `rms[P]=-6.685`이며 엄격한 정상 수렴에 실패했다.
- 마지막 200회 평균은 `CL=-0.7280`, `CD=0.10309`; `CL` 범위는 약 0.0200이다.

따라서 이 결과는 `provisional`이며 정상 다운포스 지도에 사용하지 않는다. 다음 판단은 높은 지상고의 부착유동 조건에서 동일 절차를 시험해 수치 설정 문제와 `h/L=0.10` 조건의 본질적 비정상성을 분리하는 것이다. 필요하면 해당 조건을 URANS로 전환해 시간평균과 힘 스펙트럼을 분석한다.

높은 지상고 격자 생성 과정에서 초기 형상 정의가 입구·출구 높이를 절대 좌표로 고정한 문제를 발견했다. 이 방식은 큰 `h/L`에서 목 곡선이 상부 형상과 교차하며, 서로 다른 지상고에서 동일 형상이라는 조건도 위반한다. 입구와 출구를 각각 `h + 0.06L`, `h + 0.10L`로 수정했다. 기존 `h/L=0.10` 형상은 수치적으로 동일하므로 provisional 진단은 유지하되 전체 형상 계열은 새 정의로 재생성한다.

## 2026-07-13 — h/L=0.20 medium 정상 RANS

- 수정된 동일형상 정의와 moving ground를 사용해 medium 격자를 생성했다.
- 1차 정확도 안정화 해석은 265회에 `rms[P] < 1e-8`로 종료했다.
- 1차 해를 restart로 사용한 2차 정확도 계산을 2,000회 수행했다.
- 마지막 200회 평균은 `CL=-0.89235`, `CD=0.071870`이다.
- 상대 힘 범위는 CL 4.55%, CD 1.31%이며 최종 `rms[P]=-6.806`이다.
- 엄격 기준과 screening 기준을 모두 통과하지 못했으므로 상태는 `provisional`이다.

`h/L=0.20`의 2차 정확도 해는 반복이 진행되는 동안 힘이 계속 표류했다. 이 값은 정상 다운포스 곡선의 확정점으로 사용하지 않는다. 동일 설정의 정상 RANS 수렴 실패가 반복되는 낮은 지상고 조건은 강제 heave 이전에 고정 형상 URANS를 수행해 시간평균, 힘 진폭, 지배 주파수를 확인할 후보로 분류한다.

실행기는 solve 전에 기존 `config.cfg`, `history.csv`, `su2.log`, `forces_breakdown.dat`를 `runs/<timestamp>/`에 자동 보관하도록 변경했다. 이번 1차 안정화 이력과 2,000회 2차 이력도 각각 보관했다. 이 디렉터리는 대용량 로컬 계산 산출물이므로 Git에서는 제외한다.

## 2026-07-13 — h/L=0.15 medium 정상 RANS

- 1차 정확도 안정화 해석은 271회에 `rms[P]=-8.012`로 종료했다.
- restart 기반 2차 정확도 계산을 2,000회 수행했다.
- 마지막 200회 평균은 `CL=-1.00970`, `CD=0.086884`이다.
- 상대 힘 범위는 CL 2.82%, CD 1.55%이며 최종 `rms[P]=-7.272`이다.
- 엄격 기준과 screening 기준을 모두 통과하지 못했으므로 상태는 `provisional`이다.

평균 다운포스 크기는 `h/L=0.20`보다 증가했지만 2차 정확도 힘은 반복 중 계속 표류했다. 기존 `h/L=0.10` provisional 결과에서 다운포스가 다시 작아졌으므로 정상 다운포스 최대점은 우선 `0.10 < h/L < 0.15`로 묶는다. 다음 정상 선별점은 이 구간 중앙인 `h/L=0.125`가 적절하다. 두 경계점 모두 확정 수렴값이 아니므로 이 구간은 정량 임계값이 아닌 후속 조건 선정용 bracket이다.

## 2026-07-13 — h/L=0.125 medium 정상 RANS 시도

기본 1차 정확도 설정은 adaptive CFL 사용 시 124회, 고정 `CFL=0.5`에서도 320회에 `Residual > 10^20`으로 발산했다. 저속 초기화와 연속 restart 절차를 적용했다.

1. `MGLEVEL=0`, `CFL=0.1`, 난류 CFL 감소계수 0.1로 500회 초기화
2. `MGLEVEL=0`, `CFL=0.5`로 1,000회 연속 계산
3. `MGLEVEL=0`, `CFL=1.0`으로 2,000회 연속 계산
4. 발달한 restart에서 `MGLEVEL=3` 재시험: 약 136회에 동일 발산 재현
5. `MGLEVEL=0`, 2차 정확도, `CFL=0.2`로 2,000회 계산

마지막 2차 계산의 200회 평균은 `CL=-0.50883`, `CD=0.03201`이며 최종 `rms[P]=-5.590`이다. CL 상대 범위는 1.27%지만 CD 상대 범위가 87.2%로 매우 크고 계산 종료 시점까지 빠르게 변화했다. 따라서 결과는 `provisional`이며 정상 다운포스 최대점 판정에 사용하지 않는다.

이 조건에서는 multigrid를 켤 때 초기장과 무관하게 발산이 반복됐고, multigrid를 끄면 발산은 억제되지만 정상 힘으로 수렴하지 않았다. `h/L=0.125`는 정상 RANS 반복을 더 연장하기보다 고정형상 URANS로 전환해 시간평균과 힘 스펙트럼을 조사할 우선 조건으로 지정한다.
