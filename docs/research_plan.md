# 연구계획

## 목적과 범위

본 연구는 단순화한 벤투리형 레이싱카 언더플로어가 강제 수직운동할 때 나타나는 비정상 공력 히스테리시스를 CFD로 계산하고, 공력이 진동에 공급하는 주기당 에너지를 이용해 포포이징 불안정 조건을 찾는다. 휠과 세부 공력장치는 초기 범위에서 제외한다.

## 단계별 수행

### M1 — 2차원 정상 기준해석

1. moving ground와 SST RANS 조건을 검증한다.
2. 지상고 스윕으로 다운포스 증가, 최대, 붕괴 구간을 찾는다.
3. 세 격자에서 힘 계수와 압력분포의 독립성을 확인한다.
4. 공개된 지면효과 익형 또는 디퓨저 자료와 경향을 비교한다.

완료 기준은 정상 수렴, 질량 불균형 허용범위 만족, 중간·미세 격자 간 다운포스 차이 2% 이내다. 박리 임계점에서는 별도의 민감도 기준을 보고한다.

### M2 — 2차원 강제 heave URANS

운동은 `h(t)=h0+A sin(2*pi*f*t)`, 감소진동수는 `k=pi*f*L/U`로 정의한다. 부착, 임계, 붕괴 영역의 평균 지상고를 선택하고 진폭과 감소진동수를 순차 스윕한다. 최소 5–10주기를 계산하고 연속 주기의 힘과 공력 일이 수렴한 뒤 마지막 주기를 분석한다.

### M3 — 단순화 3차원 언더플로어

유한 폭 벤투리 유로와 후방 디퓨저를 구성한다. 2차원에서 선별한 안정, 최대 히스테리시스, 다운포스 붕괴 조건을 우선 계산한다. 측면 누설, 가장자리 와류, 디퓨저 박리 및 와류 붕괴를 비교한다.

### M4 — 구조동역학 결합

먼저 `m*z'' + cs*z' + ks*z = F'_aero`의 1자유도 모델을 사용한다. 준정상 모델과 `h`, `h_dot`, 유동 이력을 포함한 축소모델을 비교한다. `W_aero-E_damp > 0`인 영역과 시간적 진폭 성장 여부를 함께 이용해 불안정 경계를 정의한다.

### M5 — 안정성 지도와 보고서

평균 지상고–감소진동수 공력 에너지 지도, 유속–감쇠비 안정성 지도, 2D–3D 차이, 수치 불확실성과 URANS 한계를 정리한다.

## 우선 실험행렬

정상해석은 넓은 지상고 간격으로 시작하고 최대 다운포스 부근만 적응적으로 세분화한다. 비정상해석의 초기 수준은 평균 지상고 3개, `A/h0 = 0.05, 0.10`, `k = 0.02, 0.05, 0.10, 0.20`이다. 전수조합보다 2차원 선별 후 3차원 확인을 원칙으로 한다.

## 주요 위험과 대응

- SU2 동적 격자 버전 차이: 설치 버전을 기록하고 단일 운동 검증 케이스부터 수행한다.
- 최소 지상고 격자 뒤틀림: 변형 영역 분리, 품질 자동 검사, 필요 시 overset/ALE 지원 솔버를 대안으로 평가한다.
- URANS의 박리 예측 한계: 주요 조건에서 시간간격, 격자, 난류모델 민감도를 보고한다.
- 히스테리시스 부호 오류: 모든 후처리는 `Fz`와 `z_dot`의 순간 동력 적분으로 교차검증한다.
