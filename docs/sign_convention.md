# 좌표와 부호 규약

- `x`: 차량 전방에서 후방으로 양수
- `y`: 차량 중심에서 좌측으로 양수
- `z`: 지면에서 위쪽으로 양수
- `h`: 지면과 언더플로어 기준점 사이 거리
- `Fz > 0`: 차체에 작용하는 위쪽 힘
- `downforce = -Fz`: 아래 방향 공력을 양의 다운포스로 표시

차체 변위는 `z_body > 0`일 때 위쪽이며 `h=h0+z_body`다. 공기가 차체에 한 일은

`W_aero = integral_0^T Fz(t) * z_dot(t) dt = closed_integral(Fz dz)`

로 계산한다. `W_aero > 0`은 에너지 공급, `W_aero < 0`은 공력 감쇠다. 다운포스를 사용해 적분할 경우 부호가 반대이므로 에너지 계산에는 반드시 원래의 `Fz`를 사용한다.

기준 길이는 언더플로어 유효 길이 `L`, 감소진동수는 `k=pi*f*L/U`, 힘 계수 기준 동압은 `q=0.5*rho*U^2`로 고정한다. 2차원 계수는 단위 폭 기준 면적 `L*1 m`, 3차원 계수는 실제 평면 기준면적을 사용하며 두 값을 직접 비교할 때 기준면적을 명시한다.

SU2의 전체 `CL`, `CD`는 `body_lower`, `body_trailing`, `body_upper`, `body_leading` 네 경계의 합으로 계산한다. 언더플로어 작동 원리와 압력 회복은 `body_lower`만 별도로 후처리하며, 전체 차체 힘과 하부 기여를 혼동하지 않는다.
